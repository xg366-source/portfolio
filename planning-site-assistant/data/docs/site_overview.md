# 基地概况（项目资料汇编，数据来源见文末）

## 研究范围
研究范围位于纽约皇后区 Junction Blvd—Corona—Woodside 一带走廊，以 studio 作业 Food System Atlas 的研究边界外扩约 1.5km，共覆盖 113 个 census tract。范围内总人口 396,050 人。

## 人口构成
范围内西裔/拉丁裔人口 192,232 人，占 48.5%；亚裔（非西裔）110,309 人，占 27.9%。空间分布呈明显梯度：东部 Corona 一带西裔占比达 70%–90%，走廊中部为过渡带，向西往 Woodside 降至约 20%。

## 数据来源
人口图层来自 ACS 2024 五年估算 B03002 表；治安、311、餐厅卫生等图层的来源与口径见《数据口径说明》。本汇编为项目组整理资料，引用时以原始公开数据为准。
